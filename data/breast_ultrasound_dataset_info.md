# 📷 Breast Ultrasound Images Dataset (BUSI)

Devido aos limites de tamanho de arquivo do GitHub, o arquivo compactado de imagens não está armazenado diretamente neste repositório.

## 🔗 Link para Download
* **Fonte Original (Kaggle):** [Breast Ultrasound Images Dataset (BUSI)](https://www.kaggle.com/datasets/aryashah2k/breast-ultrasound-images-dataset)

## 📌 Instruções de Uso
1. Faça o download do arquivo `.zip` através do link acima.
2. Extraia o conteúdo gerando a pasta `Dataset_BUSI_with_GT` dentro deste diretório (`data/`).
3. Alternativamente, a célula inicial do notebook `notebooks/02_visao_computacional_cnn_busi.ipynb` realiza a instrução de download diretamente durante a execução no Google Colab.
