# 🩺 Tech Challenge - Fase 1 | Pós-Graduação FIAP

Este repositório contém a solução do **Tech Challenge (Fase 1)** da Pós-Graduação em Inteligência Artificial para Devs da FIAP. O projeto consiste em um sistema inteligente de suporte ao diagnóstico médico de câncer de mama utilizando o dataset *Breast Cancer Wisconsin*.
